What discovery seeks

Three numeric finding types, five retrieval targets. Sections and Evidence use the targets below to locate useful visible filing text.

Annual profit/net income or loss
The annual shareholder earnings amount helps describe the company’s earnings level. Numeric finding type: annual profit.
Diluted EPS
Annual diluted earnings per share gives the earnings amount per common share. Numeric finding type: diluted EPS.
Annual diluted weighted-average shares
The EPS denominator context helps interpret per-share earnings; it is not year-end shares outstanding. Numeric finding type: diluted shares.
Earnings-change explanations
Help locate context for why earnings changed; no dedicated published output type.
Restatement/comparability passages
Help locate context for whether periods can be compared; no dedicated published output type.

Retrieval relevance is a search signal, not financial correctness or published evidence. Findings validates exact source quotes and amounts before publication; a finding can retain an unresolved type. The pipeline extracts reported values; it does not compute EPS from profit and shares.

What Findings delivers

A list of reported numbers sought for the filing’s current fiscal year. Each finding includes an amount, an exact filing quote, a source-line link, and a numeric type or unresolved type. Period, unit, attribution, and limitations accompany it when supported; unclear fields remain unresolved.

Illustrative finding: Diluted EPS · 2025 · $6.20, backed by a quoted filing row and a link to that source line. This is an example, not a saved run result.

Three types does not mean exactly three findings: several numbers, missing types, unresolved types, or an empty result are possible. Earnings-change and comparability passages provide context, without separate narrative findings. Source validation does not establish financial correctness; independent comparison comes later in Evaluate.
